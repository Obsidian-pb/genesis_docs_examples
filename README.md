# Библиотека genesis — документация и примеры

Репозиторий содержит документацию и примеры применения библиотеки **genesis** — инструмента пространственной оптимизации размещения подразделений пожарной охраны.

Документация опубликована на GitHub Pages: https://obsidian-pb.github.io/genesis_docs_examples/

## Решаемые задачи

- **BLP** (Best Location Problem) — определение наилучшей дислокации единственного подразделения
- **MCLP** (Maximal Covering Location Problem) — определение наилучшей дислокации множества подразделений
- **LSCP** (Location Set Covering Problem) — определение количества подразделений при наилучшей дислокации
- Моделирование и анализ параметров прибытия подразделений
- Определение оптимальных границ районов выезда
